# `_ai/` — AI 생성 자산 전용 폴더

이 폴더는 **Claude(또는 다른 AI)가 생성한 이미지만** 저장합니다.

## 규칙

- 🚫 **AI는 절대 `public/images/` 최상위에 직접 파일을 저장하지 않는다.**
- ✅ AI 생성 결과는 항상 `public/images/_ai/` 아래에 저장.
- ✅ 사용자가 마음에 들어서 정식으로 채택할 때만, **사용자가 직접** 상위 폴더로 이동 (또는 본인 디자인으로 덮어쓰기).

## 이유

5/15에 AI가 사용자의 원본 PNG (쿠션·화분·돼지)를 묻지 않고 덮어써서 손실이 발생함. 다시는 일어나면 안 됨.
